# PyXie Feedback

Bug reports, feature requests and feedback for **PyXie Manager**, a browser-based Proxmox VE operations console.

The easiest way to send feedback is from inside PyXie: **Platform > Feedback** (or the *Send feedback* link at the bottom of the sidebar). It opens a new issue here, prefilled with your PyXie version and the details you chose to include. You review it before anything is submitted.

You can also [open an issue directly](../../issues/new/choose).

## Please don't include

Passwords, API tokens or secrets, private keys, or anything else you would not post publicly. **This repository is public**: anything you submit is visible to everyone. Remove hostnames, IP addresses and VM names from logs unless they matter to the problem.
